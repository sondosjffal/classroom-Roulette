برنامج عجلة أسماء الطلاب - تعليمات البناء الآمن

1) أنشئ مستودعًا جديدًا Private على GitHub.
2) ارفع Classroom_Roulette_Final.py إلى جذر المستودع.
3) أنشئ الملف .github/workflows/build.yml وانسخ محتوى build.yml الموجود بهذه الحزمة.
4) افتح Actions ثم Build Classroom Roulette EXE ثم Run workflow.
5) بعد نجاح التشغيل افتح صفحة التشغيل ونزّل Artifact باسم Classroom-Roulette-Windows-EXE.
6) فك ZIP الناتج وافحص EXE بواسطة Microsoft Defender قبل تشغيله.

تنبيه: لا يمكن ضمان خلو أي ملف من كل المخاطر. هذا المشروع مصدره Python واضح، والبناء يتم عبر GitHub Actions.
